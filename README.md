# TCC — Arquitetura de bancos de dados para recuperação em sistemas de recomendação

Projeto de pesquisa (TCC) que investiga arquiteturas de banco de dados para a etapa
de **recuperação** de dados em sistemas de recomendação. O desenho completo do
experimento está em [CONTEXTO.md](CONTEXTO.md), a fonte de verdade do projeto.

Este documento será atualizado ao longo do projeto conforme novas etapas forem
implementadas.

## Fases do projeto

### Fase 1 — Preparação da massa de dados

Geração e preparação da massa de dados utilizada nos experimentos. Os arquivos
desta fase estão na pasta [`data_generation/`](data_generation/).
